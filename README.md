#Customer Churn Prediction

![Customer Churn Banner](assets/churn-banner.jng)

📌** Project Overview**

Customer churn is one of the biggest challenges in the telecom industry. Retaining existing customers is significantly more cost-effective than acquiring new ones.

This project aims to analyze customer data and build machine learning models to predict which customers are likely to leave the service, helping businesses design targeted retention strategies.

🎯 **Objective**

Predict customer churn using historical customer data.

Identify key factors influencing churn.

Build a robust binary classification model.

**Dataset**

Dataset Used: Telco Customer Churn
